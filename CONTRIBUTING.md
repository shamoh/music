# Contributing to Scales

Thank you for your interest in contributing! Bug reports, ideas and pull
requests are welcome.

## Before you start

- For larger changes, please open an issue first so we can agree on the
  approach before you invest time in it.
- Run the tests before submitting: `node --test 'tests/**/*.test.js'`.
- All source code, comments and documentation are written in English.
